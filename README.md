# kaj_ebooks

This is a basic Python port of [@harrisj's](https://twitter.com/harrisj) [iron_ebooks](https://github.com/harrisj/iron_ebooks/) Ruby script and [Heroku Ebooks](https://github.com/tommeagher/heroku_ebooks) with updated API calls to Twitter API v2

### Features

tweetspirals
>will occasionally spam 2-5 posts over the course of 15 minutes (max)

autoreply/qrt
>will occasionally qrt/reply to kajposts

allcaps
>will occasionally post in allcaps
